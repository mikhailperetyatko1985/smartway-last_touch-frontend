#Widget "Remove mass send button" 

##Dev
- Сгенерировать архив с виджетом для разработки можно с помощью команды:
```bash
make build-dev
```
Эта версия отличается от продакшен виджета тем, что в файле script.js лежит прокси на localhost разработчика, что
позволяет разрабатывать виджет не перезаливая архив каждый раз при изменении js и css файлов.  
Генерировать и заливать архив с виджетом необходимо например в случае изменения манифеста, ленгов или изображений.  

Чтобы поднять локальный сервер для раздачи кода виджета, за которым ходит прокси надо выполнить команду:
```bash
make run
```

Либо без докера поднять локальный dev сервер напрямую через webpack
```bash
make run-npm
```

##Production
Сгенерировать архив с виджетом для прода можно с помощью команды:  
```bash
 make build-prod
 ```
